# Wallpapers

WacOS doesn't ship any wallpapers (Apple's are Apple's). Put your own here if you like:

- `lock.png`: the lock screen picture. Without it the lock screen uses your desktop wallpaper.
- Or point `lock_wallpaper` in `config.ini` at any picture, or set it to `desktop`.

The desktop wallpaper is Windows' own: Settings > Personalization > Background, or System
Settings > Wallpaper in WacOS.
